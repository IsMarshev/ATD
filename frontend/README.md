# Адаптивный дизайнер тестов — фронтенд

Next.js + TypeScript приложение, которое визуализирует работу с бэкендом ATD (FastAPI). UI собирает историю генераций, детальные сценарии и экспорт напрямую из API, поэтому перед запуском убедитесь, что сервер работает.

## Быстрый старт

```bash
npm install
# по умолчанию фронтенд ожидает API на http://localhost:8000/api
npm run dev
```

Если бэкенд запущен на другом хосте или порту, задайте переменную окружения `NEXT_PUBLIC_API_URL`, например:

```bash
NEXT_PUBLIC_API_URL="http://127.0.0.1:8000/api" npm run dev
```

## Скрипты

- `npm run dev` — запуск разработки с горячей перезагрузкой.
- `npm run build` — production-сборка.
- `npm run lint` — проверка ESLint.

## Основные маршруты

- `/` — дашборд с фильтрами, метриками и актуальными событиями из API.
- `/generate` — создание новой генерации с загрузкой датапула и отправкой запроса на бэкенд.
- `/editor?id={testCaseId}` — табличное редактирование шагов, перегенерация и просмотр чата для выбранного кейса.
- `/changes?id={testCaseId}` — подбор шагов, требующих внимания, и анализ покрытия требований.
- `/export?id={testCaseId}` — подготовка экспорта, сопоставление полей и журнал выгрузок.
- `/integrations` — статический экран с подключениями Adaptavist, Zephyr и Excel.

Статические справочные данные (модели, проекты, тестовые типы) лежат в `src/data/mockData.ts`, а работа с API — в `src/lib/api.ts`.
