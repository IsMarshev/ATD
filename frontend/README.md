# Адаптивный дизайнер тестов — фронтенд

Next.js + TypeScript приложение, прототипирующее интерфейс Adaptive Test Designer для оркестрации генерации тест-кейсов с помощью ИИ. Включены основные экраны: история запусков, новая генерация, редактор кейса, сравнение версий, экспорт и интеграции.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000, чтобы изучить интерфейс. Проект использует App Router и Tailwind CSS v4. Для проверки корректности кода доступна команда `npm run lint`.

## Маршруты

- `/` — дашборд с фильтрами, метриками и актуальными инцидентами.
- `/generate` — загрузка датапула, выбор моделей, настройка правил регенерации и предпросмотр созданной группы кейсов.
- `/editor` — табличное редактирование шагов с подсветкой нарушений и чатом с моделью для уточнений.
- `/changes` — сравнение версий и выборочное применение изменений.
- `/export` — подготовка экспорта, предпросмотр сопоставления полей и журнал результатов.
- `/integrations` — управление подключениями Adaptavist, Zephyr и Excel.

Все данные условные и находятся в `src/data/mockData.ts` — их можно изменять для демонстрации разных сценариев.
